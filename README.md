# 高兴里

**读懂一座村，走近这里的人。**

以四川邛崃天台山镇高兴村为背景的文化导览与乡村体验设计原型。独立学生设计提案，非官方平台。

## 打开原型

下载本仓库后，使用浏览器打开 `index.html`。全部界面与素材均在仓库内，无需安装依赖。

也可在仓库目录运行：

```sh
python -m http.server 8765
```

然后访问 `http://localhost:8765`。

- `index.html`：移动端交互原型，桌面提供手机预览。
- `design.html`：视觉方向板、研究依据、设计假设与后续验证问题。
- `wireframe.html`：低保真流程。
- `验证记录.txt`：已完成的检查与验证边界。

## 试玩流程

读扁担故事 → 加入参访意向 → 选择本地讲述 → 提交模拟咨询 → 顶部“接待演示”回复 → “我的行程”确认 → 导出随行卡。

支持待回复、待你确认、已确认、无法接待、已取消五种状态。接待方修改建议安排后，需要游客再次确认。可调整地点顺序、移除地点、切换大字、生成PNG图片和打印行程。

## GitHub Pages

本仓库首页位于根目录，可在仓库 **Settings → Pages → Deploy from a branch → main / (root)** 启用静态托管。部署完成后的网址以 GitHub Pages 返回结果为准；GitHub Pages 的国内网络可达性需要由实际网络验证。

## 数据与素材边界

所有咨询只保存在当前浏览器的 localStorage，不对外发送，不接入真实预约、支付或村务系统，不跨设备同步。可在“出行与服务”中清除本机演示记录。不要填写真实敏感信息。

文化资料出处标注在页面和设计说明中。开放时间、交通、费用、接待主体均待当地确认。演示确认不构成真实预约。

SVG为原创意象占位图，非高兴村实景、文物复原或历史影像。字体优先使用本机思源宋体/黑体，缺失时使用系统中文字体。未进行村民现场访谈，不声称已经证明服务效果。

## 检查

```sh
node --check app.js
node tests/model-test.cjs
```
